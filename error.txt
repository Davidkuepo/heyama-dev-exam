🚨 ERREUR: MongoDB n'est pas installé!

SOLUTION: Installe MongoDB avec l'une de ces commandes:

═══════════════════════════════════════════════════════════════

OPTION 1: Installation Directe (Ubuntu/Debian)
═══════════════════════════════════════════════════════════════

Copie et exécute ces commandes une par une:

sudo apt-get update

sudo apt-get install -y mongodb

sudo systemctl start mongodb

sudo systemctl enable mongodb

Vérifie l'installation:
mongod --version

Puis lance MongoDB:
mongod

═══════════════════════════════════════════════════════════════

OPTION 2: Avec Docker (Recommandé - Plus Simple!)
═══════════════════════════════════════════════════════════════

Si tu as Docker installé, exécute:

cd /home/david/Documents/heyama-dev-exam

./start-docker.sh

Mongo Express sera accessible à: http://localhost:8081

═══════════════════════════════════════════════════════════════

APRÈS L'INSTALLATION:

Ouvre 3 terminaux différents et lance:
